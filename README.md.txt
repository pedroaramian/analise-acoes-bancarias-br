# Análise de Ações Bancárias com Python

## Sobre o projeto

Este projeto tem como objetivo analisar o desempenho histórico de ações de bancos brasileiros utilizando Python. A análise permite comparar o comportamento dos ativos ao longo do tempo, calcular retornos e visualizar seus desempenhos por meio de gráficos.

O projeto também utiliza o ETF BOVA11 como referência para comparação com o mercado brasileiro.

## Ativos analisados

- **BBAS3** — Banco do Brasil
- **ITUB4** — Itaú Unibanco
- **SANB4** — Santander Brasil
- **BBDC4** — Bradesco
- **BMGB4** — Banco BMG
- **BRSR6** — Banrisul
- **BOVA11** — ETF de referência do mercado brasileiro

## Tecnologias e bibliotecas utilizadas

- Python
- Jupyter Notebook
- yfinance
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Plotly

## Análises realizadas

- Coleta de dados históricos dos ativos financeiros.
- Organização e tratamento dos dados com Pandas.
- Cálculo e comparação de retornos.
- Análise do desempenho histórico das ações.
- Criação de gráficos para visualização dos dados.
- Comparação das ações bancárias com o BOVA11.

## Como executar o projeto

1. Instale as bibliotecas necessárias:

```bash
pip install yfinance pandas numpy matplotlib seaborn plotly
```

2. Abra o arquivo `conjuntos_bancario.ipynb` no Jupyter Notebook ou no Visual Studio Code.

3. Execute as células do notebook em ordem.

**Observação:** é necessário ter conexão com a internet para obter os dados históricos pelo yfinance.
